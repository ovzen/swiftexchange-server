# 🚀 SwiftExchange Server

**Лёгкий сервер для обмена файлами и буфером обмена по локальной сети**

---

## 📝 Краткое описание

Сервер с графическим интерфейсом для обмена файлами и текстом между устройствами в одной Wi-Fi сети. Поддерживает загрузку любых файлов, синхронизацию буфера обмена и имеет удобный GUI для управления.

---

## ⚡ Быстрый старт

### Установка

```bash
git clone https://github.com/yourusername/swiftexchange.git
cd swiftexchange/server
pip install -r requirements.txt
```

### Запуск

```bash
python main.py
```

Нажмите **«Запустить сервер»** – сервер готов к работе!

---

## 🔧 Основные возможности

- ✅ **Файлы:** загрузка, скачивание, удаление
- ✅ **Буфер обмена:** синхронизация текста между устройствами
- ✅ **GUI:** удобное управление сервером
- ✅ **Настройки:** порт, папка загрузок, лимит размера, автозапуск
- ✅ **Большие файлы:** потоковая загрузка до 1 ГБ и выше
- ✅ **Логи:** все события отображаются в окне
- ✅ **Кроссплатформенность:** Windows, Linux, macOS

---

## 📱 Использование

1. **Запустите сервер** (`python main.py` → кнопка «Запустить сервер»)
2. **Запомните IP-адрес**, который появится в логах (например, `http://192.168.1.100:8000`)
3. **На телефоне** в настройках клиента укажите этот IP и порт
4. **Обменивайтесь файлами и текстом!**

---

## ⚙️ Настройки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| **Порт** | Порт для подключения | 8000 |
| **Папка загрузок** | Куда сохранять файлы | `uploads/` |
| **Макс. размер файла** | Ограничение загрузки | 1024 МБ |
| **Автозапуск** | Старт при открытии программы | Выключено |

Настройки сохраняются в `config.json`.

---

## 🔌 API

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/files` | Список файлов |
| POST | `/upload` | Загрузить файл |
| GET | `/download/{filename}` | Скачать файл |
| DELETE | `/delete/{filename}` | Удалить файл |
| GET | `/clipboard` | Получить текст |
| POST | `/clipboard` | Установить текст |

## 📦 Сборка .exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "SwiftExchangeServer" --add-data "server_app.py;." --add-data "uploads;uploads" main.py
```

Готовый `.exe` появится в папке `dist`.

## ❓ Частые вопросы

**Как узнать IP сервера?**  
Смотрите логи при запуске или выполните `ipconfig` в командной строке.

**Где хранятся файлы?**  
В папке `uploads` (можно изменить в настройках).

**Почему сервер не запускается?**  
Проверьте, свободен ли порт (8000 по умолчанию). Измените порт в настройках.

**Буфер обмена сбрасывается?**  
Да, при перезапуске сервера текст очищается (хранится в памяти).

**Можно ли из интернета?**  
Только через VPN или проброс портов (не рекомендуется без HTTPS).
